# Fastify Production Template

A professional, modular Fastify application setup using TypeScript.

## Folder Structure
```text
src/
├── server.ts         # Main server entry point
├── config.ts         # Environment validation and config exports
├── plugins/          # Fastify plugins (e.g., logger)
├── middleware/       # Custom hooks and global handlers
├── routes/           # Fastify routes (e.g., health)
└── utils/            # Shared utilities
```

## Setup
1.  `npm install`
2.  `npm run dev`
